# Privacy Policy

_Last updated: November 10, 2026_

Script Editor for Azure DevOps does not collect, store, transmit or sell any personal data.

- **What it reads.** On `dev.azure.com` and `*.visualstudio.com` pages, the extension reads the script text boxes of pipeline tasks so it can show them in a code editor, and writes your edits back to those same text boxes. This happens entirely inside your browser.
- **What it stores.** Your editor preferences (theme, font size, line wrapping) are saved with the browser's `chrome.storage.sync`, which your browser may sync across your own signed-in devices. Nothing else is stored.
- **Network.** The extension makes no network requests. All of its code ships inside the extension package; no remote code is loaded.
- **Third parties.** No analytics, tracking or third-party services are used.

Questions: open an issue at https://github.com/maxijabase/ado-script-editor/issues.
